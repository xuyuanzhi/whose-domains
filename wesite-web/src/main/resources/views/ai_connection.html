Connect to AI assistants

Whose.Domains exposes a read-only Model Context Protocol (MCP) endpoint, so ChatGPT and other MCP-capable assistants can look up domain registration data on your behalf.

MCP endpoint: https://whose.domains/mcp
Transport: Streamable HTTP
Authentication: none (anonymous, read-only, rate limited)

Tools

  • check_domain — registration status for a single domain.
  • check_domains — a small batch of domains in one call.
  • get_domain_info — full registration detail (registrar, dates, name servers, registry statuses, WHOIS/RDAP endpoints).

Status values: registered, available, unregistered_candidate, reserved, unknown. A missing DNS record or a failed lookup never means a domain is available — only available means a confirmed registrable name, and this service currently reports unregistered_candidate when a registry simply has no record.

Connect in ChatGPT

  1. Open Settings → Apps & Connectors → Advanced settings and enable Developer mode.
  2. Choose Create and enter a name, for example “Whose.Domains”.
  3. Set the MCP server URL to https://whose.domains/mcp and select No authentication.
  4. Scan the tools and start a conversation; ask the assistant to check a domain.

This connector is currently usable as a custom connection only. It has not been submitted to, or approved for, the public ChatGPT app directory.

Test locally

Use the MCP Inspector against a local instance:

npx @modelcontextprotocol/inspector # Streamable HTTP -> http://localhost:8080/mcp
